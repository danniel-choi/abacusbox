# AbacusBox 애드센스·SEO 14일 보고서

작성일: 2026-10-23
상태: 1주차 분석·기술 기반 정리 및 핵심 계산기 콘텐츠 개선 단계

## 수행한 작업

- 프로젝트 구조와 빌드 방식을 조사했다.
- Next.js App Router, static export, Cloudflare Pages + Functions + D1 구조를 확인했다.
- 189개 계산기, 41개 블로그, 11개 허브, 260개 정적 라우트를 확인했다.
- metadata, canonical, robots, sitemap, JSON-LD 구현을 조사했다.
- AdSense client/slot과 광고 배치 컴포넌트를 조사했다.
- GA4 연결과 D1 방문자 통계 구현을 확인했다.
- Chrome DevTools MCP가 현재 연결되지 않아 실측 성능 감사를 수행하지 못했다.
- Search Console과 AdSense 계정 데이터는 권한이 없어 확인하지 못했다.
- 최저임금·퇴직금·DSR/LTV 계산기 3개에 고유 SEO 콘텐츠와 관련 계산기 내부 링크를 추가했다.
- 위 3개 계산기의 계산 로직은 변경하지 않고 lint, typecheck, production build를 통과시켰다.
- 빌드 산출물에서 세 페이지의 title, canonical, 보강 콘텐츠 반영을 확인했다.
- 홈페이지에 `계산의정석 계산기`, `계산의 정석 계산기`, `무료 온라인 계산기`, `생활 계산기 모음` 및 주요 계산기 내부 링크를 반영했다.
- 로또 6/45 등수별 확률과 번개 피격 확률 참고 계산기를 추가해 총 262개 정적 라우트를 생성했다.
- 번개 확률은 미국 NWS의 과거 추정치를 기본 참고값으로만 사용하고 지역별 차이를 안내했다.

## 현재 결론

- 코드상 공개 핵심 페이지를 차단하는 전역 `noindex`는 확인되지 않았다.
- sitemap과 canonical 기반은 마련되어 있다.
- 실제 색인 누락과 순위 하락의 원인은 Search Console 데이터 없이는 단정할 수 없다.
- 검색 성장의 다음 병목은 핵심 계산기 콘텐츠 품질, 외부 신뢰 신호, 실제 성능 측정일 가능성이 있으나 이는 가설로 관리한다.
