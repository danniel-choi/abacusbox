# AbacusBox 애드센스·SEO 실행계획

작성일: 2026-10-23

## 원칙

- 색인·검색·수익 수치는 Search Console, GA4, AdSense에서 확인한 값만 사용한다.
- 신규 페이지는 검색 의도와 독창적인 설명이 확인될 때만 만든다.
- 계산 공식과 법률·세무·금융 기준은 공식 출처와 검산으로 확인한다.
- 광고 수익을 위해 클릭을 유도하거나 광고를 콘텐츠로 위장하지 않는다.

## 완료된 기반 작업

- `www.abacusbox.com` canonical 기준 통일
- `robots.txt`의 `/sitemap.xml` 연결
- 계산기·블로그·허브 sitemap 구성
- 계산기·블로그·허브별 구조화 데이터 추가
- GA4 측정 ID 연결
- 저가치 자동 블로그 생성량 축소
- 홈페이지 광고 위치와 콘텐츠 길이 개선
- 브랜드 연관 검색어를 홈페이지 title, keywords, 분야별 디렉터리 내부 링크에 자연스럽게 반영

## 1주차

### 1일차: 데이터 확인

- Search Console 최근 3개월 성과와 색인 제외 사유 확인
- 사이트맵 처리 상태 확인
- GA4 실시간·랜딩 페이지 확인
- AdSense 페이지 RPM과 광고 노출 확인

### 2일차: 기술 SEO

- 허브별 Open Graph title/description/url 보강
- 실제 canonical과 sitemap URL 일치 확인
- 오류·중복·soft 404 URL 목록화
- 불필요한 URL을 sitemap에서 제외할지 검토

### 3~5일차: 핵심 계산기 개선

임시 후보:

- 최저임금
- 실수령액
- 퇴직금
- 연말정산 환급액
- 대출 DSR/LTV

Search Console 데이터를 받은 뒤 최대 3~5개로 확정한다.

이번 실행에서는 데이터 권한이 없는 상태의 임시 우선순위로 다음 3개를 먼저 반영했다.

- `/calculators/minimum-wage`: 월급·주휴시간·임금 항목 안내와 관련 계산기 연결
- `/calculators/severance`: 평균임금·퇴직 전 3개월·계속근로기간 안내와 관련 계산기 연결
- `/calculators/loan-dsr`: DSR/LTV 차이·상환액·금융기관 심사 한계 안내와 관련 계산기 연결

계산 로직은 변경하지 않았으며, 정적 HTML 생성 결과와 canonical을 확인했다.

각 페이지에 추가할 내용:

- 사용 목적
- 입력값과 가정
- 계산 공식
- 기준일
- 검산 예시
- 예외 조건
- 공식 출처
- 관련 계산기와 가이드 링크

### 6일차: 광고·모바일

- 모바일 계산기 입력과 결과 가독성 점검
- 광고가 입력창·결과·버튼을 가리지 않는지 확인
- 광고 슬롯별 요청·노출·CLS 측정
- 슬롯 분리 여부는 실제 수익 데이터 확인 후 결정

### 7일차: 검증

- lint, typecheck, build
- 주요 URL canonical·robots·sitemap 검사
- 핵심 계산기의 정상값·경계값·오류 입력 검증
- Search Console 색인 요청 대상 목록 작성

## 2주차

- 검색 데이터 기반 콘텐츠 추가
- 검증된 신규 계산기 최대 1~2개 구현
- 관련 허브와 블로그 내부 링크 강화
- 페이지별 SEO title/description 개선
- 광고 수익과 검색 성과의 기준선 기록

## 수익 목표 관리

월 10만 원, 30만 원, 100만 원은 운영 목표이며 보장값이 아니다. 다음 식으로 실제 데이터가 쌓인 뒤 관리한다.

`예상 월수익 = 페이지뷰 ÷ 1,000 × 페이지 RPM`

RPM과 페이지뷰를 확인하지 않은 상태에서는 목표 달성 기간이나 필요한 트래픽을 추정하지 않는다.
