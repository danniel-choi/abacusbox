# 자동 업데이트 시스템

## 운영 방식

Cloudflare Worker `calcrule-blog-scheduler`가 매일 UTC 03:05(한국시간 12:05)에 실행됩니다.

자동 실행 범위는 다음과 같습니다.

- 최근 계산기 주제에서 검토용 블로그 초안 1건 생성
- 다음 계산기 개발 후보를 후보(candidate)로 등록하고 최대 2건을 계획(planned) 상태로 보강
- 관리자가 예약한 초안 중 공개 시각이 지난 글만 자동 공개
- 실행 결과를 D1의 `scheduler_runs`에 기록

자동 생성 초안과 새 계산기는 즉시 공개하지 않습니다. 세금·노무·금융 수식, 출처, 기준일, 모바일 UI를 검토한 뒤 관리자 화면에서 승인·예약해야 공개됩니다. 이는 자동 생성 콘텐츠가 검색 품질을 떨어뜨리거나 법률·세무 기준을 잘못 안내하는 위험을 줄이기 위한 운영 장치입니다.

## 확인 위치

관리자 화면의 스케줄러 로그에서 최근 실행 시각, 공개 건수, 생성 초안, 계산기 후보와 오류를 확인할 수 있습니다. 예약 공개는 관리자 화면에서 게시 시각을 지정하면 다음 스케줄 실행 때 처리됩니다.

## 외부 계정 설정

Cloudflare Worker에는 `calcrule-prod` D1 바인딩이 필요합니다. HTTP 수동 실행 경로를 사용할 경우 `CRON_SECRET`을 Worker/Pages 환경변수에 설정해야 합니다. Google Search Console과 AdSense 데이터는 별도 API 권한이 연결되지 않는 한 자동 변경·수집하지 않습니다.

## 롤백

자동 실행을 일시 중지해야 하면 Cloudflare Worker의 cron 트리거를 비활성화하거나 배포 전 버전으로 되돌립니다. 공개 전 초안은 삭제하지 않고 관리자 화면에서 검토·보류 상태로 관리합니다.
