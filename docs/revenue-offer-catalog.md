# AbacusBox 수익화 제안 상품 기준

작성일: 2026-11-25  
상태: 검증용 제안안 — 확정 가격·매출이 아님

## 목적

광고 수익만으로 월 500만 원을 판단하지 않고, 무료 계산기와 템플릿을 통해 실제 사업자 수요를 확인한 뒤 디지털 상품과 B2B 서비스를 제안한다.

## 제안 상품

| 상품 | 대상 | 제공 범위 | 판매 방식 | 현재 상태 |
| --- | --- | --- | --- | --- |
| 사업자 마진 CSV 템플릿 | 1인 사업자·판매자 | 판매가·원가·광고비·기타비용·마진율 표 | 무료 샘플 → 유료 확장판 검토 | 무료 샘플 배포 |
| 맞춤 계산 템플릿 | 반복적으로 숫자를 관리하는 사업자 | 입력 항목·공식·출력표를 업무에 맞게 설계 | 문의 후 범위·가격 확정 | 문의 검증 |
| 계산기 위젯 | 외부 사이트·커뮤니티·사내 페이지 | 임베드 UI, 계산 로직, 사용 안내 | 구축 범위와 유지보수 협의 | `/business/widget-demo` 데모 공개·문의 검증 |
| 계산기 API·관리 | 반복 호출이 필요한 기업 | API 키, 호출량, 장애 안내, 운영 지원 | 계약·보안·사용량 검토 후 제공 | 미구현 |

## 운영 원칙

- 가격은 원가·지원 범위·책임 범위를 확인하기 전 확정하지 않는다.
- 결제·환불·세금 처리 주체와 약관이 정해지기 전에는 유료 결제 버튼을 노출하지 않는다.
- 무료 샘플은 `template_sample_click`, `template_download`, `template_lead_click`로 수요를 측정한다.
- B2B 문의는 `widget`, `template`, `partnership` 유형을 D1에 저장하고 관리자 화면에서 건수와 최근 시각만 집계한다.
- 실제 구매·문의 데이터가 없는 동안 전환율, 고객 수, 상품 매출을 추정하지 않는다.

## 목표 산식

월 매출은 다음처럼 실제 결제·광고 보고서로 분리해 기록한다.

`월 합계 = AdSense 수익 + 디지털 상품 순매출 + B2B 계약 매출 + 제휴·후원 수익`

월 500만 원은 운영 목표일 뿐 보장값이 아니다. 필요한 판매량이나 광고 페이지뷰는 실제 단가와 RPM을 확인한 뒤 역산한다.

## 다음 판단 기준

1. 7일 이상 이벤트 수집 후 무료 템플릿 다운로드가 실제로 발생했는지 확인
2. 템플릿 문의와 위젯 문의 중 어느 유형이 발생했는지 비교
3. 문의가 발생한 유형에만 샘플 확장판 또는 견적 안내를 준비
4. 결제·환불·약관·세무 처리가 준비된 경우에만 유료 판매 구현
